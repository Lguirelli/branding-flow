# Brand Flow — Branding Kit App

MVP front-end para portfólio, criado com HTML, CSS e JavaScript puro.

## Fluxo

1. Tela inicial com nome e botão de começar
2. Escolha do arquétipo principal em carrossel
3. Escolha opcional do arquétipo secundário
4. Nodes de fonte principal
5. Nodes de font pairing
6. Nodes de cor principal
7. Nodes paralelos para cor secundária, destaque, fundo e texto
8. Preview final da marca

## Identidade fixa do app

A interface usa a paleta Sunflower Fields:

- #D6D6D6
- #FFEE32
- #FFD100
- #202020
- #333533

A interface usa Cal Sans + Inter via Google Fonts.

Essas escolhas são fixas do app e não interferem no brand kit criado pelo usuário.

## Cores e fontes dinâmicas

As escolhas do usuário afetam apenas:

- preview da marca
- variáveis `--brand-*`
- JSON exportado

## Arquivos principais

- `index.html`
- `styles.css`
- `app.js`

## Como rodar

Abra o `index.html` no navegador ou publique a pasta no GitHub Pages.
